# Latent Insider Information Shocks

This repository implements a point-in-time transaction-level insider-information
shock pipeline for U.S. equities. The public repository contains code,
configuration, public summary tables, static figures, and HTML companions.

Raw WRDS extracts, processed row-level panels, logs, manifests, model binaries,
and credentials are intentionally excluded from Git.

Current public-safe run evidence is summarized in [Run Status](run_status.md).
